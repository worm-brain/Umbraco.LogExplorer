# Keyboard shortcuts

Every control in the explorer can be reached with Tab and is labelled for screen readers. These
shortcuts work on the Search view when focus is not in a text field (except where noted); keys
pressed elsewhere in the backoffice are left alone.

## Search view

| Key | Action |
| --- | --- |
| `/` | Focus the search box. |
| `j` / `k` | Move down / up the results, scrolling as needed. |
| Enter | Open the focused result in the entry drawer. |
| Escape | Close an open menu; otherwise close the entry drawer; otherwise clear the search box. In an empty search box, move focus to the results. |

## In the search box

| Key | Action |
| --- | --- |
| Enter | Turn the input into chips and search. |
| Backspace | In an empty box, remove the last chip. |
| Escape | Clear what you have typed. |

## Histogram

The bars are one Tab stop.

| Key | Action |
| --- | --- |
| Left / Right | Move to the previous / next bar. |
| Home / End | Move to the first / last bar. |
| Enter or Space | Zoom in on the focused bar. |

## Fields panel divider

Focus the divider between the fields panel and the results.

| Key | Action |
| --- | --- |
| Arrow keys | Resize the panel; hold Shift for bigger steps. |
| Home / End | Make the panel its narrowest / widest. |
| Double-click | Reset the width. |

## Menus

The time range and source pickers are menu buttons.

| Key | Action |
| --- | --- |
| Up / Down, Home / End | Move between choices. |
| Enter | Choose, and return focus to the button. |
| Escape | Close the menu and return focus to the button. |
| Tab | Leave the menu. |
